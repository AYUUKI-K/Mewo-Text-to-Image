# 喵喵文生图

SillyTavern 文生图扩展，仅支持 NovelAI。配合世界书输出提示词，将正文中的图片标签变成生成按钮。

## 安装

在酒馆「扩展程序 → 安装扩展程序」粘贴：

```text
https://github.com/AYUUKI-K/Miao-Text-to-Image
```

安装后刷新页面，在扩展设置中找到「喵喵文生图」。需要酒馆后端支持 `/api/novelai/generate-image` 和 NovelAI 密钥管理。

## 使用

1. 输入自己的 NovelAI API Key，点击保存。密钥存入酒馆密钥管理。
2. 设置画师串、固定正面与负面提示词、画布大小和生成参数；支持复制、删除和切换多套配置。
3. 默认模式下，AI 输出的 `image###提示词###` 转成「生成插图」按钮，点击后开始生成。
4. 启用「流式自动生成」后，本次 AI 回复中每个完整的图片标签闭合时立即入队，逐张生成。
5. 首次启用自动载入默认世界书与四份配套正则，也可以导入自己的世界书和正则。使用不同输出格式时，需要修改捕捉表达式，第一捕获组为绘图提示词。

最终正面按「固定正面 → 画师串 → 本次图片提示词」拼接，负面单独发送。图片保存在酒馆图片目录，路径与生成参数记录在消息中；历史聊天加载不会自动生成图片。

错误会在酒馆弹窗显示。若酒馆后端将上游详细错误简化为 HTTP 500，弹窗只能展示后端返回的信息。

## 资源管理

默认世界书由 NUE-喵喵电波编写。已有同名世界书、同 ID 或同名正则会复用，不覆盖现有内容。导入自己的世界书不会自动关闭其他世界书，可在酒馆世界书面板选择启用项目。

插件总开关控制图片处理。已导入的世界书与正则可在酒馆各自的管理面板停用。

## 开发版状态

版本：0.1.0。已实测 NovelAI `nai-diffusion-4-5-full` 生成 512×512 图片，并完成 SillyTavern 1.18.0 的设置页生成、图片保存和弹窗展示测试。正文按钮与多图流式的真实聊天端到端测试仍需补充。

流式模式指文本输出期间标签闭合后生成图片，不包含 NAI 中间预览图。暂不包含配置导入导出、取消已发出的生成请求、Guidance Rescale 参数和资源自动停用。

切换聊天或修改原消息后，旧任务结果不会插入新位置；已发出的请求可能仍消耗额度，返回图片会保存在酒馆图片目录。
