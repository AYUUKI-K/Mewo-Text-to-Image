# 喵喵文生图

SillyTavern 文生图扩展，仅支持 NovelAI。配合世界书输出提示词，将正文中的图片标签变成生成按钮。

## 安装

在酒馆「扩展程序 → 安装扩展程序」粘贴：

```text
https://github.com/AYUUKI-K/Mewo-Text-to-Image
```

安装后刷新页面，点击聊天输入框旁的魔棒，在菜单中打开「喵喵文生图」。原版酒馆需要后端支持 `/api/novelai/generate-image` 和 NovelAI 密钥管理。TT 酒馆使用设备直连 NAI，在插件中填写并保存 Key 后使用；勾选记住后可在刷新后恢复。

## 使用

1. 输入自己的 NovelAI API Key，点击保存。密钥存入酒馆密钥管理。
2. 在「配置」页设置模型、正面与负面提示词、画布大小和生成参数；支持复制、删除和切换多套配置。
3. 默认模式下，AI 输出的 `image###提示词###` 转成「生成插图」按钮，点击后开始生成。
4. 在「生成」页选择最新楼层的处理方式：手动、自动（开启期间的新回复完成后）、流式（完整标签闭合后）。自动和流式均只处理开启期间的新回复；旧标签、关闭期间的标签只显示手动按钮，不在开启、换模式或重载聊天时补跑。
5. 首次启用自动载入默认世界书与四份配套正则，也可以导入自己的世界书和正则。使用不同输出格式时，需要修改捕捉表达式，第一捕获组为绘图提示词。

最终正面按「前置正面 → 本次图片提示词 → 后置正面」拼接，负面单独发送。旧配置的正面保留在前置，后置默认为空。图片保存在酒馆图片目录，路径与生成参数记录在消息中；历史旧楼层不会自动生成；最新楼层按所选模式处理。

错误会在酒馆弹窗显示。若酒馆后端将上游详细错误简化为 HTTP 500，弹窗只能展示后端返回的信息。

## 资源管理

内置世界书由 NUE-喵喵电波编写，当前内容为 2.1。更新插件后，在「资源」页点击「更新资源」。已有 2.0 会升级为「[喵喵]文生图 2.1」：同标题条目替换为新版，保留条目编号和用户额外条目；全局、角色、用户角色与聊天绑定同步迁移。若 2.0、2.1 已同时存在，会合并为一份 2.1；确认绑定保存后移除旧名，不留两本。其他历史聊天在打开时迁移旧绑定。

四份正则按 ID 或名称覆盖；喵喵文生图配套规则还会识别旧日期后缀并去重，避免 0820、0511 与 1024 重复执行。导入自定义世界书的同名条目、同名或同 ID 正则也会更新。资源更新不会自动关闭其他世界书。

插件总开关控制图片处理。已导入的世界书与正则可在酒馆各自的管理面板停用。

## 版本与验证

版本：1.2.1。已实测 NovelAI `nai-diffusion-4-5-full` 生成 512×512 图片，并完成 SillyTavern 1.18.0 的设置页生成、图片保存和弹窗展示测试。V5 已核对官方模型 ID，并覆盖普通酒馆转发及直连请求参数测试，未消耗额度进行 V5 实际生成。TT 删除已按当前项目接口在桌面／手机浏览器中验证交互，未在实体 TT 客户端验收。大图缩放已通过桌面和手机视口的双指、拖动、滚轮、双击及复原检查，尚未用实体手机联调。正文按钮与多图流式的真实聊天端到端测试仍需补充。

流式模式指文本输出期间标签闭合后生成图片，不包含 NAI 中间预览图。暂不包含配置导入导出、取消已发出的生成请求、Guidance Rescale 参数和资源自动停用。

切换聊天或修改原消息后，旧任务结果不会插入新位置；已发出的请求可能仍消耗额度，返回图片会保存在酒馆图片目录。

## 服务器存储与按日期清理

图片保存在酒馆服务器，浏览器不保存图片本体。在魔棒 → 喵喵文生图 → 图片页，可以修改 `user/images` 下的子目录（默认 `miao-nai`）；修改只影响之后生成的图片，旧目录仍可从管理目录中选择，不自动搬迁旧文件。当前使用酒馆标准图片接口，不提供任意绝对路径或 S3 配置。

按日期显示本插件生成图片数量，可清理单个日期或勾选多个日期批量清理。日期按访问设备时区归类。只识别本插件 `miao-时间戳` / `test-时间戳` 命名的 PNG，兼容初版文件。删除前确认数量，永久清理服务器文件后，引用原图的历史聊天将不能显示它；仍可手动重新生成。清理不会删除整个聊天或同目录中的其他图片。
