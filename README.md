# 喵喵文生图

SillyTavern 文生图扩展，仅支持 NovelAI。配合世界书输出提示词，将正文中的图片标签变成生成按钮。

## 安装

在酒馆「扩展程序 → 安装扩展程序」粘贴：

```text
https://github.com/AYUUKI-K/Miao-Text-to-Image
```

安装后刷新页面，点击聊天输入框旁的魔棒，在菜单中打开「喵喵文生图」。需要酒馆后端支持 `/api/novelai/generate-image` 和 NovelAI 密钥管理。

## 使用

1. 输入自己的 NovelAI API Key，点击保存。密钥存入酒馆密钥管理。
2. 设置画师串、固定正面与负面提示词、画布大小和生成参数；支持复制、删除和切换多套配置。
3. 默认模式下，AI 输出的 `image###提示词###` 转成「生成插图」按钮，点击后开始生成。
4. 在「生成」页选择最新楼层的处理方式：手动、自动（载入或回复完成后）、流式（完整标签闭合后）。自动和流式均只处理最后一层；所有旧楼层仅保留手动按钮。
5. 首次启用自动载入默认世界书与四份配套正则，也可以导入自己的世界书和正则。使用不同输出格式时，需要修改捕捉表达式，第一捕获组为绘图提示词。

最终正面按「固定正面 → 画师串 → 本次图片提示词」拼接，负面单独发送。图片保存在酒馆图片目录，路径与生成参数记录在消息中；历史聊天加载不会自动生成图片。

错误会在酒馆弹窗显示。若酒馆后端将上游详细错误简化为 HTTP 500，弹窗只能展示后端返回的信息。

## 资源管理

默认世界书由 NUE-喵喵电波编写。已有同名世界书、同 ID 或同名正则会复用，不覆盖现有内容。导入自己的世界书不会自动关闭其他世界书，可在酒馆世界书面板选择启用项目。

插件总开关控制图片处理。已导入的世界书与正则可在酒馆各自的管理面板停用。

## 开发版状态

版本：0.2.0。已实测 NovelAI `nai-diffusion-4-5-full` 生成 512×512 图片，并完成 SillyTavern 1.18.0 的设置页生成、图片保存和弹窗展示测试。正文按钮与多图流式的真实聊天端到端测试仍需补充。

流式模式指文本输出期间标签闭合后生成图片，不包含 NAI 中间预览图。暂不包含配置导入导出、取消已发出的生成请求、Guidance Rescale 参数和资源自动停用。

切换聊天或修改原消息后，旧任务结果不会插入新位置；已发出的请求可能仍消耗额度，返回图片会保存在酒馆图片目录。

开发测试：

```sh
npm test
```

## 0.2.0 更新

设置从扩展列表移到魔棒菜单。独立面板提供生成、提示词、参数、资源、图片五个分页，支持蓝白浅色、蓝黑深色与跟随酒馆，适配移动端。

载入聊天时仅最后一个楼层能按模式自动生成；例如 #3 和 #5 都有标签，只自动处理 #5。如果最后一层是用户消息，不回退生成旧的 AI 楼层。已有图片、失败任务和重复渲染不会反复自动请求。排队中的自动任务在轮到时再次检查是否仍是最新楼层。

## 服务器存储与按日期清理

图片保存在酒馆服务器，浏览器不保存图片本体。在魔棒 → 喵喵文生图 → 图片页，可以修改 `user/images` 下的子目录（默认 `miao-nai`）；修改只影响之后生成的图片，旧目录仍可从管理目录中选择，不自动搬迁旧文件。当前使用酒馆标准图片接口，不提供任意绝对路径或 S3 配置。

按日期显示本插件生成图片数量，可清理单个日期或勾选多个日期批量清理。日期按访问设备时区归类。只识别本插件 `miao-时间戳` / `test-时间戳` 命名的 PNG，兼容初版文件。删除前确认数量，永久清理服务器文件后，引用原图的历史聊天将不能显示它；仍可手动重新生成。清理不会删除整个聊天或同目录中的其他图片。

## 隔离验证

`node tests/preview-server.mjs` 启动本地隔离预览（127.0.0.1:8766）。预览替换了 NAI 和文件接口，不发送真实生成请求、不删除真实图片。启动时验证新旧楼层按钮、最新楼层自动生成、重复载入去重、旧楼层手动生成和完整流式标签。
